# Discrete Math

Interactive materials that help students connect discrete mathematics concepts to computing.

## Live Application

🌐 https://discretemath-umflint.streamlit.app/

## Current Topics

### Chapter 1: Logic

- Propositions and Logical Operators
- Conditional Statements
- Truth Tables
- Logical Equivalences and Laws
- Predicates and Quantifiers
- Negating Quantified Statements
- Nested Quantifiers
- Translating English Statements into Logic
- Rules of Inference

### Chapter 6: Relations

- Binary Relations as Tables
- Same-Set Relations
- Graph Representations
- Matrix Representations
- Reachability and Transitive Closure
- Equivalence Relations
- Partial Orders and Hasse Diagrams
- N-ary Relations, SQL, and Datalog
