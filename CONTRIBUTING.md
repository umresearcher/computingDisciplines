# Contributing

Thank you for your interest in contributing to Computing Across Disciplines.

We welcome:

- Bug reports
- Feature requests
- Suggestions for new ounces of computing
- Improvements to existing materials
- New disciplinary applications of computing concepts

## Reporting Issues

Please use GitHub Issues to report bugs, request features, or suggest improvements.

## Contributing Content

Contributions should support the goals of the project:

- Computing serves disciplinary learning goals.
- Disciplinary learning goals remain paramount.
- Computing is introduced in authentic disciplinary contexts.
- Materials should be usable, accessible, and sustainable.

Contributions are reviewed by the project maintainers for alignment with the goals of the project.

Contributions may be incorporated, modified, adapted, or declined by the project maintainers.
